# VR Ninja
A Fruit Ninja-inspired VR slicing game built as my minor project using Unity XR. Developed in around 3 months while learning VR from scratch. Features a timer mode and an interactive VR menu.

https://github.com/user-attachments/assets/f45636b9-bf53-44b6-99be-f5cce4ec2b55

## 🎮 Key Features
* **Physics-Based Slicing:** Implemented real-time mesh slicing using the **Ezy-Slice framework**, allowing players to cut objects at any angle.
* **Arcade Gameplay Loop:** Includes a complete game loop with object spawning systems, score tracking, and a timed survival mode.
* **Interactive VR UI:** Designed a fully interactive 3D menu system for level selection and settings, moving away from standard 2D overlays.
